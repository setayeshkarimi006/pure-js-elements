# ✨ Interactive UI Components

A modern, responsive, and interactive web project built with **HTML, CSS, and Vanilla JavaScript**. This project demonstrates essential front-end development skills through a collection of reusable-style UI components, smooth interactions, and a clean user interface.

## 🚀 Features

### 🖼️ Interactive Image Slider
- Navigate between images using previous and next buttons.
- Switch directly to a specific image using navigation dots.
- Automatically wrap around when reaching the beginning or end of the image list.
- Keep the active image and navigation indicators synchronized.

### 📑 Dynamic Tabs
- Switch between different content panels without reloading the page.
- Update the active tab and its corresponding content dynamically.
- Use JavaScript event handling and `data-*` attributes to connect tabs with their panels.

### 🔽 Custom Dropdown Menu
- Open and close the dropdown with a simple click.
- Select an option and dynamically update the displayed value.
- Close the menu automatically after making a selection.
- Handle option clicks efficiently using event delegation.

### 🪟 Interactive Modal
- Open the modal using a dedicated button.
- Close it using the close button or the Continue button.
- Dismiss the modal by clicking the overlay outside the dialog.
- Prevent clicks inside the modal content from accidentally triggering the overlay's closing behavior.

2. Open the project folder.
3. Open `index.html` in your browser.

No additional JavaScript libraries or frameworks are required.
